顺手可以一起加的功能

这些在稿子里已占好位置，勾选后才实现，不勾选不影响视觉方案。

记住账号 低成本

用 DPAPI 加密存到用户目录，下次自动填 IP / 账号，密码可选。

服务器连通检测 低成本

启动前 TcpClient 探测一次（800ms 超时），不通就直接提示，不白等。

客户端自检 低成本

把现有的 FindGameLauncher 结果显式展示出来，缺文件时给出可点击的路径提示。

启动主服务器 低成本

复用现有 CSNZ_Server.exe 逻辑，一键起服再进游戏，单人测试很省事。

公告 / 更新日志 中成本

读取本地 news.txt，或拉取一份远程 JSON；离线时静默隐藏该区块。

自动更新 高成本

需要补丁包与校验流程，建议单独立项，不放进本次 UI 改版。
